# cercis-core（内核）

Cercis 内核：**行业普适的"文件夹即数据库"引擎**。

- 只做两件事：**数据存取**（表/记录/文件/历史/查询原语）与 **AI 友好**（数据契约/机器清单/JSON/权限）
- 不认识任何学科概念；字段语义由工具包模板提供
- 用 Rust 编写；目标：单二进制、全平台、离线可用
